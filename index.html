Medienwerkstatt

A private, self-hosted tool that produces short animated story videos and publishes them to the operator's own YouTube channels.

What it does

  • Writes short fictional stories, turns them into narrated vertical videos with illustrations and subtitles.
  • Uploads the finished videos to YouTube channels owned by the operator, using the YouTube Data API.
  • Reads view, like and comment counts of those uploaded videos to learn which stories work best.

Who uses it

Only the operator. It is not a public service: there are no user accounts, no sign-ups and no third-party channels. The software runs on the operator's own computer.
